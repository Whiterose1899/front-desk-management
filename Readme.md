The following project is made for Hotels to smoothly handle their bookings, gain useful insights, and provide a comfortable stay for their guests.

It contains the following features:
1. Guest Management
2. Room Management
3. Reservation System
4. JWT Authentication
5. Role-Based Access Control - Admin, Manager, and Staff
6. Email Notification System - Upon reservation, check-in, check-out, and cancellation
7. Automated Check-In and Check-Out Reminder Emails.
8. Analytics for the Company to improve its logistics
